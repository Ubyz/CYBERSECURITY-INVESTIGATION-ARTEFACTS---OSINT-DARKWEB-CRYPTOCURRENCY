# Viewing the Email Files
The two email artefacts are provided as .eml files. This is the best way to preserve email evidence so we can view the email header and how the email looked to the recipient.

To view these correctly, install Mozilla Thunderbird from the internet - a coordinator will help if you require support

Thunderbird is an email client that does not require any of your personal details, investigators use this software to open .eml files so they are not opening them in their professional email clients. This creates separation between our investigations and day jobs.

Once you have Thunderbird downloaded (you do not need to set a username or password) you can open .eml files that you have downloaded to your device. File > Open > Open saved files >
